# Daily Speaking Challenges Module (Phase 9)

## Responsibilities
- Serves globally synchronized daily speaking prompts.
- Community leaderboard ranking attempts by accuracy and fluency.
- Streak bonus multipliers and milestone XP rewards.
- Automatic archiving and scheduled topic rotation.

## Key Entities
- `DailyChallenge`: Date, topic, prompt text, target duration (60s), CEFR difficulty.
